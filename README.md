Vice City Cover Studio turns any photo into a GTA-style sunset-neon poster cover: pick a multi-panel layout, drop in photos, crop and position each panel, style the big title lettering, pick a colour grade, and export a print-ready PNG. It runs fully offline in the browser — photos never leave the page.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a desktop browser.

## Shortcuts

- Ctrl/Cmd+E — export the current size as PNG
- Keys 1–4 — switch the colour grade (Sunset / Neon / Vice City / Noir)
