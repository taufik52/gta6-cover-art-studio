Vice City Cover Studio turns any photo into a GTA-style sunset-neon poster cover, right in the browser. Pick a multi-panel layout, drop photos into the panels, drag to reposition and scroll to zoom each photo, style the big title lettering, choose a colour grade, and export a print-ready PNG. Everything runs fully offline — no uploads, no network — and three procedural sample scenes let you try it with a single click.

## Run it

```sh
cd app
python3 -m http.server 8080
```

Then open <http://localhost:8080> in a desktop browser.

## Shortcuts

- **Ctrl/Cmd+E** — export the current size as PNG
- **1–4** — switch the colour grade (Sunset / Neon / Vice City / Noir)
