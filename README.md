Vice City Cover Studio turns any photo into a GTA-style sunset-neon poster cover. Pick a multi-panel layout, drop photos into the panels, crop and position each one, style the big title lettering, choose a colour grade, and export a print-ready PNG — all fully offline in the browser, so your photos never leave your machine. It ships with three procedural sample scenes so you can try it with one click.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a desktop browser.

## Shortcuts

- Ctrl/Cmd+E exports the current size as PNG.
- Keys 1–4 switch the colour grade: Sunset / Neon / Vice City / Noir.
